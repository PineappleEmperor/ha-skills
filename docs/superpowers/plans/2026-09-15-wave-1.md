come out with two green PRs, one local-only branch, and three friction logs that say where

## Global Constraints

- Nothing is committed or pushed until the maintainer says go for that repository.
- **The session pushes nothing, to any of these three repositories** (decision 3). Every
  commit it makes is local, in the clone under `.tmp/work/`; the maintainer pushes. The
  `.github/workflows/`-over-SSH rule is about this repository's own branches and does not
  loosen that.
- The reviewer agent (`.claude/agents/reviewer.md`, brief `docs/review.md`) runs on every
  branch before a push is handed over.
- No AI-attribution trailer or line in any commit, PR, comment or doc.
- Commit subjects: one imperative, Conventional Commit type, lowercase after the colon, no
  trailing period, no `and`. The commit-msg hook enforces the shape where a repo carries
  one; parcel-ha carries none and this plan adds none there, so its subjects are checked
  against release-flow's hook by hand before the commit list is handed over.
- Deliberately aligned blocks are kept, fenced with `# fmt: off` / `# fmt: on`, per
  decisions 22–28 and the rule Task 7 of the skill-refresh plan writes into `scaffold.md`.
  A code pass never collapses a table a human aligned.
- No version is ever hand-written; the release tag sets `manifest.json` at publish.
- Callers, not bodies; copies, not paraphrases. A caller is copied from the owning CI
  repository's README with `{{sha}}`/`{{tag}}` resolved; a plain workflow is copied from
  `plugins/ha/skills/ha-integration/templates/`. The only permitted differences are the
  table under *Sanctioned adaptations — the complete list* in `reference/github-actions.md`.
- Pins at the time of writing (re-resolve at execution; use the newer if moved):
  release-flow `aa2b6aaf8dadccd1f6ed5c65df774cf5f96091ae # v1.1.4`,
  ha-integration-ci `7aae20dcc8854e14197dd259d15f6368d1478eba # v1.0.4`,
  ha-panel-ci `cf32b7da07f7a31f68b6af1a3a80ef8b6f6ac3b7 # v1.1.2`.
- Friction log: one file per repo, `claude-skills/.tmp/friction/<repo>.md`, one bullet per
  event in the exact shape:
  `- <reference file> · <heading> · said: … · true: … · did: …`
  A subagent that fills a gap from its own knowledge without a bullet has broken the plan.
- **A claim is checked against the file that owns it before it is written down** (decision
  34). The rule is written into the brief itself, below, so an executor pasting the brief
  verbatim carries it.
